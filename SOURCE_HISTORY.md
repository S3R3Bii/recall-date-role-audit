# Original prediction-study hold

The original proposal required initial-notice feature provenance and a valid final-remedy target. The current flat-file ODATE definition is manufacturer owner notification, which does not establish physical first remedy availability. Current remedy prose does not establish historical initial-versus-amended values.

Those limits remain. The new bounded execution audits source event roles and date evidence, and demonstrates a typed-event guard. It does not claim to have trained or validated the original prediction model or recovered unobserved historical availability.
