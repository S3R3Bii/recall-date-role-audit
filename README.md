# Keep recall notification dates attached to their event

A notification date is not automatically the date a repair became available. A timing dataset needs the document, event role and whether a date was planned or reported to have occurred.

**Current state: fixed protocol; target campaign data and comparisons not yet retrieved.** This independent audit will compare the owner-notification field with dated public documents for the first twelve numbered vehicle recall campaigns of 2023. It will retain conflicting or unavailable evidence and demonstrate a local typed-date guard.

The original proposal to predict time to final remedy from initial notices remains unexecuted. This separate document/field audit does not establish actual first remedy availability, historical initial-feature vintages, a survival-model result or an operational safety recommendation. The fixed cohort is administrative and small; it is not a representative recall sample. See [the protocol](PROTOCOL.md).
